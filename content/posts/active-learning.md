::: tldr
主动学习不是「寻找最难样本」的算法，而是一个**在总成本约束下，持续选择高边际价值数据的闭环决策系统**。

判断一套主动学习方案，顺序比算法名称更重要：先证明随机采样不够用，再确认昂贵的是新增标签而不是别的资源；随后根据候选来源选择池式、流式或生成式查询，用信息量、代表性、预期改进或学习评分估计价值，在批次层面处理冗余、覆盖与异质成本，最后用隔离测试集上的学习曲线决定继续或停止。

其中最重要的认识是：**样本价值不是固有属性，而是相对于当前模型、已有数据、目标分布和完整成本的边际量**。不确定性只是价值信号之一；一个高不确定样本可能只是噪声、歧义或分布外输入。

大模型时代并没有让数据价值问题消失，但削弱了经典逐样本主动学习的若干前提：标签不再总是主要成本，单样本影响被数据规模稀释，不确定性更难解释，多轮重训与完整评估更贵。对应的主要形态因而转向**数据选择**——从已有或生成数据中选择训练子集、去重并调整配比。
:::

在标注、训练与评估成本约束下，怎样判断是否值得做主动学习，怎样选择一批真正有边际价值的数据，又怎样证明这套选择比随机采样更划算？

## 核心问题：样本价值是边际量

给定少量已标注集合、一个候选来源和有限的查询预算，主动学习训练初始模型，按策略选择一批候选交给 oracle 标注，再更新模型并进入下一轮。目标是在更少标注或更低总成本下，达到相近或更好的目标任务表现[@2]。

一个样本「值不值得标」，取决于四个状态量：**当前模型、已有的已标注集合、目标任务分布和完整成本**。因此价值不是附着在样本上的固定分数，而是在当前状态下加入它所带来的预期边际收益。模型和已标注集一旦更新，原来的分数就会过期。

更接近工程决策的表达不是简单的「预期误差降低 / 标注成本」，而是比较一批数据带来的预期目标收益与完整闭环成本：

> **批次价值 = 预期目标收益 − 标注成本 − 质检成本 − 重训成本 − 评估成本 − 延迟成本。**

这一定义带来三条直接结论。第一，价值必须在**批次层面**估计，因为两个相似样本的联合收益远小于各自分数之和。第二，价值必须绑定**目标指标**，总体准确率与稀有类召回会给出不同排序。第三，不确定性不等于价值：高不确定性可能来自标注噪声、语义歧义或分布外输入，标完以后未必改善目标任务。

## 第一步：先判断是否值得做

主动学习不是默认优于随机采样。进入算法比较之前，先回答三个问题：

1. **随机采样是否已经足够？** 如果简单基线在预算内已经达到目标，引入选择策略只会增加推理、维护与偏差成本。
2. **昂贵的是否真是新增监督信息？** 只有新增标签或专家反馈昂贵，而且可以决定获取什么时，才直接对应经典主动学习。训练与评估昂贵会改变轮数和批量大小，却不自动构成主动学习问题。
3. **候选来源是否覆盖目标分布？** 池子本身缺失的区域无法靠打分器补回来；此时应先改变采集或生成方式。

主动学习容易在两类条件下失效。第一类是**价值信号不可靠**：模型未校准、噪声或歧义样本被高估、分布外样本被优先选择。第二类是**收益空间不足**：随机采样已经接近最优、候选来源不覆盖目标分布，或完整系统成本超过节省的标注成本。2024 年的一项系统评测也表明，在通用图像分类设定下，没有哪一个复杂方法能够稳定超过基于熵的简单基线，结论还会随起始预算、预算步长和预训练条件改变[@5]。

因此更可靠的起点是：**先证明随机采样在自己的数据分布、目标指标和成本口径下不够用，再引入主动学习。**

## 第二步：三类查询范式决定候选从哪里来

主动学习有三类经典查询范式[@3]：

| 场景条件 | 查询范式 | 典型形态 | 主要代价 |
| --- | --- | --- | --- |
| 候选可以提前收集，能够离线打分并批量送标 | **池式查询** | 历史仓库、工单、图像库 | 池子覆盖决定上限；需要维护索引和池版本 |
| 样本持续到达，必须即时决定是否请求标签 | **流式查询** | 线上日志、传感器、风控 | 标签延迟、概念漂移和反馈回路 |
| 没有现成候选，但可以生成、模拟或设计输入 | **生成式查询** | 仿真环境、生成模型、主动实验设计 | 真实性、多样性和额外验证成本 |

三者不是算法难度的递进，而是三种不同的数据获取方式。选范式时，应先问候选能否提前收集、是否按流到达、能否主动生成，再比较 acquisition function。

池式最容易做标准化实验，因为候选池固定、可以反复打分并按批送标；这也是公开 benchmark 和工具链主要围绕池式展开的原因[@3][@4]。流式的核心问题不是怎样离线排名，而是在标签延迟与分布漂移下做单条或微批决策。生成式查询则把候选产生本身也纳入优化，但生成分布是否真实会直接限制选择上限。

实际系统可以混合三种范式，例如先从历史池中离线筛选，再把线上样本缓冲成微批，并用生成补足缺失区域。范式描述主路径，不要求系统只能选择一种来源。

## 第三步：用四类信号估计价值

选样策略可以按「它相信什么信号能代表价值」分成四类：信息量、代表性、预期改进和学习评分[@1]。

<figure class="rsi-mini"><figcaption>四类选样信号：都在近似边际价值，但依赖的假设不同</figcaption><div class="rsi-mini-branches rsi-four"><div><strong>信息量</strong><span>不确定性、margin、熵、模型间分歧；假设模型越没把握越值得标</span></div><div><strong>代表性</strong><span>核心集、聚类、密度与覆盖；假设补上未覆盖区域收益最大</span></div><div><strong>预期改进</strong><span>误差下降、梯度或影响函数；尝试直接估计对目标指标的贡献</span></div><div><strong>学习评分</strong><span>从历史轮次学习样本价值；假设过去的选择经验可以迁移</span></div></div></figure>

**信息量**最便宜也最常用。最小置信度、margin 和熵只看当前模型的输出分布；Query-by-Committee 用多个模型的分歧，BALD 用预测与模型后验之间的互信息。它们都依赖同一个前提：模型知道自己什么时候不知道。校准差时，这类方法会稳定漏掉「自信但错误」的样本。

**代表性**把问题改写为覆盖特征空间。核心集方法寻找能够代表剩余数据的子集[@6]；聚类和密度方法按区域分配配额；BADGE 则把不确定性与多样性放进同一个梯度空间，避免整批集中在相似区域[@7]。这类方法对冗余更稳健，但可能忽略数量少、难度高且业务重要的切片。

**预期改进**直接尝试回答「标完以后目标指标会改善多少」。预期误差下降最接近价值定义，但通常需要昂贵的反事实估计；梯度和影响函数是更可计算的近似。**学习评分**则从历史轮次学习「什么样的数据曾经带来收益」，但容易继承过去的选择偏差。

四类信号没有普遍最优。它们分别近似边际价值的不同侧面，必须在相同候选来源、预算、训练协议与评估口径下比较。

## 第四步：从单点排序到批量选择

按单样本分数取 top-k 是最省事的做法，也是最常见的失效点。只要候选池存在大量近重复样本，top-k 就会把预算集中到同一个局部区域。

批量选择至少要同时处理四件事：

1. **冗余**：对批次内相似样本施加惩罚，避免重复购买同一条信息；
2. **覆盖**：按特征区域、类别或业务切片分配预算；
3. **配额**：保证稀有类和关键切片不会被总体分数淹没；
4. **异质成本**：专家复核、重新采集和多人交叉标注的单价并不相同。

因此目标应从「每个样本分数最高」改为「整个批次在当前状态下的净边际收益最大」。工程上不必精确求解组合优化，但必须显式记录冗余、覆盖和成本，否则单点分数再准确，也无法推出一个合理批次。

## 第五步：把选样放进完整闭环

一个完整循环包括四个执行环节：**选择、标注、入库与重训、评估**。评估之后进入独立决策门，决定启动下一轮还是停止交付。

<figure class="frontier-figure"><a href="../assets/active-learning-loop.png" title="查看原图"><img src="../assets/active-learning-loop.png" alt="主动学习闭环：未标注候选池进入选择环节，依次经过标注、入库与重训、评估，再进入继续下一轮的决策门。只有目标未达、收益足够且预算未尽时才返回选择；目标达成、收益不足或预算耗尽时交付模型、标注集与成本账。预算监控只连接决策门，固定测试集只连接评估。"></a><figcaption>图 2 · 主动学习的一轮闭环。预算监控只进入评估后的决策门；目标未达、收益足够且预算未尽时才启动下一轮。点击可看原图。</figcaption></figure>

图中的打分器与批量选择器只是闭环的一环。工程上还需要九类组件：

| 组件 | 输入 → 输出 | 典型失效 |
| --- | --- | --- |
| 候选来源与索引 | 原始样本或生成器、特征、元数据 → 候选集 | 来源不覆盖目标分布 |
| 打分器 | 模型输出、特征 → 价值信号 | 校准差、分布外样本高分 |
| 批量选择器 | 分数、相似度、成本 → 一个批次 | 批次冗余、配额失衡 |
| 标注与质检 | 批次 → 标签、置信度、争议记录 | 指南漂移、标注者不一致 |
| 数据版本 | 标签、来源、选择记录 → 可复现训练集 | 无法解释样本为何进入训练 |
| 训练与重训 | 训练集 → 新模型 | 先验偏移、重训成本被低估 |
| 独立评估 | 固定测试集 → 指标与学习曲线 | 测试集泄漏、口径漂移 |
| 监控 | 校准、漂移、类别先验 → 告警 | 信号变化无人处理 |
| 预算与停止 | 累计成本、目标指标 → 继续或停止 | 只按轮次停，不看边际收益 |

标注接口尤其不能只返回一个标签。指南版本、多人一致性、争议复核和质检结果都会改变标签价值；这些信息应回写给选择器，帮助下一轮识别「高不确定但没有标注价值」的样本。

## 第六步：用评估曲线验证并停止

主动学习的收益必须相对于基线来定义。最基本的验证图是学习曲线：横轴使用累计标注量；当样本成本差异明显时，横轴应改为累计总成本。纵轴使用预先确定的目标任务指标，同时画出随机采样与简单启发式基线。

::: diagram active-learning-curve
图 3 · 学习曲线示意（合成数据）：同一目标指标下，主动学习约 2.7k 条、仅按不确定性排序约 4.0k、随机采样约 7.2k；阴影为多种子下的一个标准差。
:::

这张图需要回答三个问题：

1. **达到目标需要多少成本？** 主动学习约 2.7k 条达到示意目标，随机采样约 7.2k；比只比较预算用尽时的最终值更有意义。
2. **相同预算下改善多少？** 在相同横坐标上比较纵轴，并把标注、质检、重训与评估成本纳入横轴。
3. **差距是否超过方差？** 多种子、不同池划分和初始化都应进入不确定性区间；落在阴影带内的差异通常不足以支持复杂策略。

选择策略会主动改变训练数据分布，因此还要同时监控先验偏移、选中集合与候选池的分布距离，以及总体指标与关键分片指标。测试集必须与选择过程隔离：既不能参与打分，也不能因为每轮结果而反复调整选择策略，否则测试集事实上已经进入训练决策。

每个被选样本至少应记录轮次、分数与打分器版本、选择器版本、标注者、成本和质检结果。这个成本账本既用于审计，也用于估计下一轮的边际收益。

停止条件只有三类：**目标指标已经达成、边际收益低于阈值、预算耗尽**。只有目标未达、收益仍足够且预算未尽时才进入下一轮。只按固定轮数停止，会把「预算用完」误当成「收益耗尽」。

## 大模型时代：主动学习的前提变化与数据选择

大模型并没有让有限预算下的数据价值问题消失，但改变了经典逐样本主动学习成立的成本结构。这里需要区分两个问题：主动学习决定**获取哪些新的标签**，数据选择决定**哪些已有或生成的数据进入训练**。两者共享边际价值和闭环验证原则，但不是同一个问题。

### 经典前提出现了哪些 Gap

| 经典主动学习的前提 | 大模型时代的变化 | 直接结果 |
| --- | --- | --- |
| 标签是主要成本 | 自动生成标签降低了部分任务的标注成本，但验证、抽检和训练仍然昂贵[@8] | 逐样本节省标签的价值下降 |
| 单样本具有可观边际影响 | 预训练与后训练数据规模更大，单样本贡献更容易被稀释 | 选择单位转向子集、能力切片和数据配比 |
| 模型不确定性可以指导选样 | 生成输出存在语义等价，token 概率和答案正确性并不一致[@9] | 不确定性仍可用，但不再等于样本价值 |
| 多轮重训与完整评估可接受 | 大模型训练和系统评估成本更高 | 更少轮次、更大批次和离线数据选择更常见 |

这些 Gap 解释了为什么逐样本主动学习不再是大模型训练的默认形态。问题并不是「主动选择」失效，而是昂贵资源从单条标签转移到了数据处理、训练与验证，操作对象也从「下一条标什么」转为「哪些数据值得进入下一次训练」。

### 数据选择是怎样的对应形态

大模型数据选择通常面对一个已经带标签、由模型生成或经过弱监督处理的大规模数据池，目标是在训练预算内选择更有效的子集或数据配方。常见信号包括：

- **质量**：正确性、完整性、可验证性和格式质量；
- **复杂度**：样本是否提供超出当前模型能力的有效学习信号；
- **多样性**：去重、覆盖能力切片，避免数据集中在少数模式；
- **目标相关性**：训练数据与目标任务分布是否匹配；
- **梯度影响**：样本对目标任务梯度或训练动态的影响。

LESS 用梯度相似度选择面向目标任务的指令数据[@10]；DEITA 将复杂度、质量和多样性用于指令微调数据选择[@11]；DSIR 则通过重要性重采样使训练数据更接近目标分布[@12]。这些工作与经典主动学习共享四条原则：价值取决于当前模型与目标、批次要处理冗余、选择会改变训练分布、收益必须用成本归一化的基线验证。

区别同样明确：经典主动学习购买新的监督信息，数据选择重组已有信息。前者主要节省标注预算，后者主要节省训练、处理与验证预算。把两者区分开，才能解释大模型时代主动学习留下了什么方法论，又有哪些经典设定已经不再成立。

::: my-take
我对主动学习的理解已经从「哪个 acquisition function 更强」，转向「系统能否解释每一批数据为什么进入训练、花费多少、带来多少可验证收益」。一个平庸的打分器配上干净的测试集和诚实的成本核算，通常比一个精巧的打分器配上泄漏的测试集更有用。

第一，**范式选择先于打分器**。候选能否提前收集、是否持续到达、能否主动生成，决定池式、流式还是生成式，也决定评估口径。第二，**acquisition function 不是护城河，可验证、可算账的闭环才是**。选择日志、数据版本、独立评估和成本账本比单个 scorer 更难替代。

第三，**大模型没有消除数据价值问题，而是把主要载体从逐样本主动标注转向数据选择**。标签不再总是最贵的资源后，更值得优化的是哪些数据进入训练、怎样去重和配比，以及单位训练与验证成本换来了多少目标收益。
:::
