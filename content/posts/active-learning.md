::: tldr
主动学习要回答的问题很朴素：**标注贵、预算有限，而未标注样本对目标任务的贡献并不相同**，能否让模型主动决定下一批请专家标什么？

本文的出发点是：**样本的「价值」不是一个固有属性，而是一个边际量**。它取决于当前模型、已有的已标注集合、目标任务分布，以及标注成本。同一个样本在训练早期和后期、在已有集合不同时，价值可以完全不同。这一点决定了后面所有工程决策：

- 三类查询范式——**生成式查询、池式查询、流式查询**——先由场景决定：能不能提前收集候选、样本是否按流到达、能否自己生成候选，比打分器排名更早决定方案形态；
- 它是一条**会自我改变分布的闭环**：选择 → 标注 → 入库重训 → 评估 → 再选择；打分器只是其中一环，候选池、测试集隔离、预算与停止准则同样决定成败；
- 批量选择要显式处理**冗余**，否则 top-k 会选出一批高度相似的样本；选择过程本身会引入**分布偏差**；
- 验证只能靠**评估曲线与成本归一化**，报告「达到某指标需要多少标注」，而不是只报最终值。

大模型时代，逐样本主动学习不再是默认选项：标注变便宜、模型不确定性信号更不可靠、单样本的边际价值被数据配比与评测成本盖过。但「在有限预算下决定下一步获取什么信息」这套方法论反而更重要，只是「获取什么」从样本上移到了切片、任务与环境。
:::

::: question
在标注成本与训练成本约束下，如何定义「值得标注」的样本，并检验新增数据的边际收益？在大模型时代，这个问题发生了什么变化？
:::

GitHub 上的开源项目 [awesome-active-learning](https://github.com/SupeRuier/awesome-active-learning) 不只是论文清单，还按问题场景、选样策略、理论、实践和应用组织资料[@1]。它引出的基本问题很朴素：标注贵、预算有限，而未标注样本对目标任务的贡献并不相同，能否让模型主动决定下一批请专家标什么？

这个问题之所以长期存在，是因为数据价值从来不等于数据数量。增加一千条样本的收益，取决于模型已经会了什么、任务还缺什么、标注一条要花多少钱，以及重训与评估要花多少时间。把这些因素放在一起，主动学习就不只是一组采样启发式，而是一个受预算约束的迭代决策问题。

一个完整的循环可以压缩成四个环节：**选择、标注、入库与重训、评估与决策**。每一轮结束时，模型变了，候选池里样本的相对价值也随之改变，下一轮必须重新估计。

四个环节分别对应：**选择**（打分与批量选择）、**标注**（Oracle 与质检）、**入库与重训**、**评估与决策**。这张图对三类查询范式都成立，区别只在候选集从哪来：预先收集、流式到达，还是模型生成。

图里有两个容易漏掉的地方。**候选池与测试集都在循环之外，却决定循环的上限**：池子不覆盖目标分布时，再好的选择策略也补不上缺失的区域；测试集一旦参与打分或决定下一轮选什么，评估曲线本身就失去意义。**监控与预算不产出训练数据，却决定循环何时停**：校准、漂移与类别先验的变化如果没人看，策略会在错误的信号上越走越远。

## 经典问题设定

给定少量已标注集合、一个候选来源（预先收集的池、持续到达的流，或一个可以生成候选的模型）和有限的查询预算，训练一个初始模型，按策略选择一批候选交给人工或领域专家（oracle）标注，更新模型后继续下一轮。最终目标是用更少标注达到相近或更好的泛化表现[@3]。这是**模型—选样—专家—再训练**的迭代式机器学习架构，不是简单按难度排序的一次性数据清洗。

更具体地说，一轮循环由几个量决定：初始已标注集、候选来源、总预算、轮数、每轮批量大小，以及每条样本的标注成本。优化目标有两种写法：在预算约束下最大化目标任务指标，或在达到目标指标的前提下最小化累计成本。后者更接近工程实践，因为「达到某个指标需要多少标注」才是可以和业务方对齐的口径。

主动学习有三类经典查询范式，区别在于候选样本从哪里来：**生成式查询（query synthesis）**由学习器自己合成候选，再请 oracle 标注；**池式查询（pool-based）**在预先收集的未标注池上挑选；**流式查询（stream-based）**在样本逐个到达时决定是否标注[@17]。三者不是难度递进，而是三种数据获取方式，评价口径也不同。

与一次性数据清洗相比，迭代式主动学习有三个额外约束。第一，**打分依赖当前模型**，模型更新后分数会过期；第二，**批次内样本会互相影响**，两个相似样本的边际价值远小于各自分数之和；第三，**训练分布被策略改变**，类别先验和困难样本比例都不再等于真实分布。忽略这三点，策略很容易在离线指标上好看、在部署后失效。

### 三类范式怎么选：先看场景

选范式时，先回答三个问题：候选样本能否提前收集？样本是否按流到达？如果两者都不行，能否自己生成或模拟候选？这三个问题对应的工程条件，比「哪个 acquisition function 更强」更早决定方案形态。

| 场景条件 | 适用范式 | 典型场景 | 主要代价 |
| --- | --- | --- | --- |
| 候选可以提前收集，能离线打分、批量送标 | **池式** | 历史仓库、工单、图像库 | 池子覆盖决定上限；特征索引与池版本要维护 |
| 样本持续到达，不能等全量，分布会漂移 | **流式** | 线上日志、传感器、风控 | 单条决策、标签延迟、漂移与反馈回路 |
| 没有现成池子，也不能等流式数据，但可以生成或模拟候选 | **生成式** | 仿真环境、生成模型、主动实验设计 | 生成分布可能不真实；多样性与验证成本 |

实际系统里常见混合形态：先用池式离线筛一轮，再把线上流式样本缓冲成微批，必要时用生成补足缺失区域。范式描述的是主路径，不是排他选择。

从 awesome-active-learning 对问题场景与实际约束的整理看，有几条工程观察值得先摆出来：

- **论文与 benchmark 大多默认池式批量设定**。候选池固定、可以反复打分、按批标注，这套设定最容易复现，也最容易做出漂亮的评估曲线；但它把「候选从哪里来」这个前提隐藏了。论文里的排名不能直接搬到流式或生成式场景[@2][@5][@17]。
- **池式最容易工程化，难点在覆盖与工作流**。数据已经躺在仓库里，标注按批次分配，重训按周期进行；真正卡住落地的是池子是否覆盖目标分布、标注团队能否按批次交付、成本账是否算得清，而不是打分器是否够新[@16]。
- **流式的难点不是打分，而是延迟标签与漂移**。样本到达时就要决定标不标，标签可能很晚才回来，分布还可能持续变化；策略必须处理「用旧标签评估新决策」的问题。
- **生成式的难点是真实性与多样性**。没有池子时，生成候选本身就是主动学习的一部分；但生成分布可能偏离目标分布，生成质量决定了选择的上限，验证成本也往往被低估。

项目对三类场景的描述本身也说明了分布不均：池式是绝大多数工作的默认设定，流式不如池式流行，查询合成在很长一段时间里发展较少[@17]。这解释了为什么公开 benchmark、工具链与工程案例都向池式倾斜。

项目列出的实际考虑包括数据、oracle、规模、工作流、训练成本、指标、可靠性与隐私等几类[@16]。这些约束说明：范式选择往往由组织条件决定，而不是由算法排名决定。这些判断需要在具体项目中逐条核对——池子是否真的覆盖目标分布、流式延迟是否可接受、生成样本是否需要额外验证。

## 一轮循环里的组件

图 1 的四个环节在工程上会展开成九类组件。把它们分清，比换一个更复杂的打分函数更能决定方案成败。

| 组件 | 输入 → 输出 | 典型失效 |
| --- | --- | --- |
| 候选来源与索引 | 原始样本或生成器、embedding、元数据 → 可检索的候选集 | 池子不覆盖目标分布；生成分布不真实 |
| 打分器 | 模型输出、特征 → 价值分数 | 校准差、分布外样本高分、分数跨轮不可比 |
| 批量选择器 | 分数、相似度、成本 → 一个批次 | 批次内冗余、配额失衡、成本模型过于简化 |
| 预算与停止准则 | 累计成本、轮次、目标指标 → 继续或停止 | 只按轮次停、不记重训与评估成本 |
| 标注接口与质检 | 批次 → 标签、置信度、争议记录 | 标注指南漂移、多标注者不一致、LLM 标注偏差 |
| 数据存储与版本 | 标签、来源、打分记录 → 可复现训练集 | 无法回溯「这批为什么被选」 |
| 训练与重训 | 混合训练集 → 新模型 | 先验偏移、灾难性遗忘、重训成本被低估 |
| 评估与基线 | 固定测试集 → 指标、评估曲线 | 测试集泄漏、单次实验、指标口径漂移 |
| 监控 | 校准、漂移、类别先验 → 告警 | 监控信号反过来成为选择信号，形成 Goodhart |

其中最容易被单独称作「主动学习算法」的，是打分器与批量选择器；但它们只占闭环的一环。**数据账本**（每个样本记录了第几轮被选、分数多少、谁标的、花了多少钱）和**停止准则**（目标达成、边际收益低于阈值、预算耗尽）通常比打分器更早决定项目能否交付。没有账本，无法解释模型为什么变好；没有停止准则，循环会一直跑到预算见底，把最后几轮的低收益样本也算进成本。

还有一类组件容易被当成基础设施而不是方法：**评估与测试集隔离**。主动学习的收益必须以「相对随机采样的增量」来表述，而这个增量只有在测试集独立时才可信。测试集既要与打分隔离，也要与「决定下一轮选什么」隔离；否则每一轮都在同一个测试集上做决策，测试集事实上已经参与了训练。

## 样本价值是边际量，不是固有属性

一个样本「值不值得标」，取决于四件事：**当前模型**、**已有的已标注集合**、**目标任务分布**、以及**标注成本**。因此它是边际量——在已有集合之上再加入一条样本所带来的期望收益，而不是这条样本自身携带的某种分数。

更可操作的写法是把价值写成比值：**预期误差降低 / 标注成本**，并且**在批次层面估计**而不是逐样本估计。批次层面的估计要处理两件事：样本之间的冗余，以及不同样本的标注成本差异。两个高度相似的样本各自分数都不错，但只值得标其中一个；一条需要专家复核的样本，成本可能是普通样本的数倍。

最常见的混淆是把**不确定性等同于价值**。高不确定性至少有两种与目标无关的来源：

- **标注噪声或本身有歧义的样本**：标了也只是把一个模糊标签固化下来；
- **分布外样本**：模型不确定是因为「没见过这种输入」，而不是「这类输入在目标分布上重要」。

两种情况都会让基于不确定性的排序退化。更隐蔽的问题是，价值会随轮次变化：第一轮很有价值的边界样本，在第十轮可能已经被相邻样本覆盖；反过来，早期被模型自信误判的样本，可能要到模型能力提升后才暴露出价值。因此**分数是有保质期的**，一次性算好的「数据价值分」只对固定的模型与已标注集成立。

## 选样策略：先看四类信号

选样策略可以按「它相信什么信号能代表价值」分成四类：信息量、代表性、预期改进和学习评分[@2]。四类信号对应不同的具体采样方法，差别在于它们假设什么信号代表价值。

<figure class="rsi-mini"><figcaption>四类选样信号：都在估计「下一条标什么最划算」，但依赖的假设不同</figcaption><div class="rsi-mini-branches rsi-four"><div><strong>信息量</strong><span>不确定性、margin、熵、模型间分歧；假设「模型越没把握的样本越值得标」</span></div><div><strong>代表性</strong><span>核心集、聚类与密度、覆盖特征空间；假设「补上没覆盖的区域收益最大」</span></div><div><strong>预期改进</strong><span>预期误差下降、梯度或影响函数；假设「能估计这一条对目标指标的直接贡献」</span></div><div><strong>学习评分</strong><span>从历史轮次学习样本价值、学习损失；假设「过去的标注决策可以迁移到未来」</span></div></div></figure>

**信息量**是最常用的一类。**最小置信度（least confident）**、**margin** 和 **熵（entropy）** 都只看当前模型的输出分布；**Query-by-Committee（QBC）** 用多个模型的分歧，**BALD** 用预测与模型后验之间的互信息来近似「标了之后能减少多少不确定」。它便宜、易实现，但前提是模型的不确定性可靠：校准差的模型会对自己错误的地方很自信，排序就退化为随机。

**代表性**把选择看成覆盖问题而不是排序问题。**核心集（core-set）** 选择一组点，使得在选中子集上训练的模型对剩余数据仍然有竞争力[@13]；**聚类**与**密度**方法按特征空间的分布分配配额；**BADGE** 则把不确定性与多样性放进同一个梯度空间，用聚类式的批量选择避免整批落在同一区域[@11]。代表性方法对冗余天然更稳健，但可能忽略真正困难的少数样本。

**预期改进**试图直接估计「标了这条之后误差会降多少」。**预期误差下降（expected error reduction）** 最贴近价值定义，代价是计算量大；**方差下降**是它的间接替代；大模型时代则更多用**影响函数 / 梯度相似度**估计一条训练样本对目标任务的影响，再按相似度选择数据[@10]。这类方法把「选择」和「训练目标」直接连起来，但依赖可计算的梯度与可信的参考集。

**学习评分**把选样本身当成学习问题：从过去轮次的「选了谁、标完后指标怎么变」里训练一个打分器。**学习损失（learning loss）** 用辅助模块预测未标注样本的损失，**策略选择**则在多个启发式之间动态切换。它在数据充足、轮次较多时有效，风险是对历史选择过拟合，越选越窄。

四类信号没有普遍最优。2024 年的一项系统评测在图像分类的通用设定下发现，没有哪一个单模型方法稳定超过基于熵的基线，部分方法甚至不如随机采样；起始预算、预算步长与是否预训练都会显著改变结论[@5]。这并不意味着策略无用，而是说明**策略的收益高度依赖实验设定**，必须在自己的数据分布与预算曲线上验证。

## 怎样验证：评估曲线与成本归一化

验证一套主动学习方案，核心是**评估曲线**，通常画成学习曲线：横轴是累计标注量（成本异质时应改为累计标注成本），纵轴是目标任务指标，同时画出随机采样与「按简单启发式排序」两条基线。图 2 是一张合成数据的示意，用来说明读图方式，而不是某次真实实验的结果。

::: diagram active-learning-curve
图 2 · 学习曲线示意（合成数据）：同一目标指标下，主动学习约 2.7k 条、仅按不确定性排序约 4.0k、随机采样约 7.2k；阴影为多种子下的一个标准差。
:::

这张图能读出三件事，也对应验证时应当回答的三个问题：

1. **达到目标要多少标注？** 看曲线与目标线的交点。主动学习约 2.7k，仅按不确定性排序约 4.0k，随机采样约 7.2k；换算成成本，前者比随机少标约 62%。报告「达到指标所需标注量」，比只报预算用尽时的终值更有信息量，因为后者会被预算大小直接决定。
2. **同样预算下差多少？** 在横轴同一位置比较纵轴，差值就是策略收益。收益还要除以成本，才能与「更便宜但更多」的标注方式比较；如果专家标注单价是普通标注的数倍，横轴必须换成累计成本，排序可能翻转。
3. **差距超过方差了吗？** 两条曲线落在阴影带内，通常不构成有效差异。阴影来自初始化、选样随机性与池子划分；单次实验里两条线交叉，往往只是噪声。

图 2 还暴露了一个常见误读：曲线后段趋平。6k 到 10k 只多出约 1.7 个点，说明继续按同一策略加标注的边际收益已经很低。此时正确的动作不是继续跑到预算耗尽，而是换策略、换切片，或者停下来检查指标是否已经饱和。

要把结论说清楚，除了曲线本身，还需要补四件事：

- **成本归一化**：报告「每单位标注成本带来的提升」，把标注、质检、重训与评估都算进去；
- **多轮与单轮对照**：一次性选一大批，与分多轮、每轮重训后再选，效果通常差别很大。多轮通常更好，但重训开销必须计入成本；
- **方差与重复实验**：多种子、多池子划分，报告置信区间而不是单点；
- **分片指标**：总体指标之外，单看稀有类、困难切片或关键失败模式，避免平均值掩盖缺口。

还要控制实验设定本身带来的差异。起始预算、预算步长与是否使用预训练，都会改变策略之间的相对排序；这些设定在论文里经常被固定成一个默认值，在工程里却各不相同，直接横向比较数字没有意义[@5]。

由此得到一条实践顺序：**先证明随机采样不够用，再引入选择策略**。反过来做，等于在还没有建立基线之前就先接受了偏差。

## 工程落地：四类实际考虑

选样信号回答「选谁」，落地还要回答四个问题：一批怎么选、偏差怎么控、账怎么算、标注怎么组织。这四类问题通常比换一个更复杂的打分器更能决定项目能否交付。

### 批量选择：从单点排序到组合覆盖

按单样本分数取 top-k 是最省事的做法，也是最容易失效的做法：如果池子里存在大量近乎重复的样本，top-k 会几乎全部落在同一个簇里。批量选择因此要额外处理三件事：

1. **冗余惩罚**：在批次内显式减去样本间相似度，或按簇分配配额；
2. **覆盖约束**：把选择看成在特征空间里的覆盖问题，而不是排序问题；
3. **异质成本**：不同样本的标注成本并不相等（需要重新采集、需要专家判断、需要多标注者交叉验证），「每个样本一票」的预算模型过于简化。

把批次看成一个集合，选择目标就从「每条样本的分数最高」变成「整个批次的边际收益最大」。这类集合目标通常不满足简单的逐点可加性，实践里用贪心加多样性约束，或先聚类再在簇内排序。工程上不必追求最优解，但必须显式处理冗余与成本，否则 top-k 的失效模式会稳定复现。

还有一个容易被忽略的口径问题：**评价指标会改变策略的评价结果**。当类别高度不平衡时，一个合理的选择策略会把预算集中到稀有类，这在「总体平均准确率」上甚至可能不如随机采样，而在「稀有类召回」上明显更好。因此策略对比必须绑定明确指标，否则结论会随指标翻转。

### 分布偏差与测试集隔离

主动学习与普通训练有一个根本差别：**训练数据的分布是被策略选出来的**。由此带来三类偏差，都需要显式报告：

- **先验偏移**：稀有类被过度采样，训练集类别先验不再等于真实先验；
- **选择偏差**：被选中的样本集中在「模型当前不确定」的区域，而模型未覆盖的区域被持续忽略；
- **评估曲线本身的偏差**：在同一个测试集上反复评估并据此做决策时，测试集事实上参与了选择过程。

前两类可以用「选中集合与候选池的分布距离」「类别先验变化」来监控。第三类只能靠制度性约束解决：**测试集必须与选择过程隔离**，既不参与打分，也不参与决定下一轮选什么。这与数据体系那篇里按来源分层记录数据配方的要求是同一条纪律[@4]。

如果测试标签本身也很贵，还有一条更积极的路径：把「选哪些测试点来标注」也当成一个主动学习问题，用少量测试标注估计模型指标，并对选择带来的偏差做校正。这就是主动评测（active testing）的思路[@8]。它和主动学习共享同一套预算逻辑，只是优化对象从训练集换成了评测集。

### 成本账本与停止准则

每个被选中的样本至少要记录：第几轮被选、分数与打分器版本、选择器版本、标注者、单价、质检结果。账本不只是审计材料，它还是下一轮估计边际收益、判断是否停止的依据。没有账本，无法解释模型为什么变好，也无法把「策略收益」和「天然数据增长」分开。

停止准则至少有三种：目标指标达成；边际收益低于阈值（阈值要带置信区间）；预算耗尽。只按轮数停止，等于把「预算用完」当成「收益耗尽」。重训与评估成本必须计入，否则多轮策略会被系统性地高估。

### 标注接口与质检

标注接口不是把样本丢给标注团队就结束。指南版本、多人一致性、争议复核、LLM 预标注的抽检比例，都会改变标签质量；而标签噪声会直接进入下一轮打分器。异质成本也在这里体现：需要专家判断的样本、需要重新采集的样本、需要多标注者交叉验证的样本，单价可能相差数倍。

把质检结果回写给选择器，通常比单独追求更复杂的不确定性估计更有效：**噪声反馈**能让下一轮避开「高不确定但其实没有标注价值」的样本，也能让停止准则更早发现「选出来的都是争议样本」。

## 什么时候主动学习不划算

选择策略不是默认更优的。以下六种情形里，它可能不产生收益，甚至更差：

1. **模型不确定性不可靠**——模型校准很差，对自己的错误很自信，基于不确定性的排序退化为随机；
2. **候选来源本身不覆盖目标分布**——选得再好也补不上缺失的区域，问题出在数据来源而不是选择；
3. **标注噪声主导**——策略优先选中的是有歧义的样本，提升的其实是拟合噪声的能力；
4. **分布外样本被优先选中**——高不确定性来自「与训练分布不同」，而非「难但相关」；
5. **预算内目标已饱和**——简单场景下随机采样已接近最优，策略收益小于它引入的偏差与工程复杂度；
6. **代价不对称**——策略的推理、重训与维护开销超过了省下的标注成本。

这六种情形可以归成两类：**信号不可靠**（1、3、4）与**收益空间不足**（2、5、6）。前者要靠更好的不确定性估计或独立验证来解决，后者要靠重新定义问题——换数据来源、换指标、或者承认随机采样已经够用。

## 大模型时代：主动学习还适用吗？

这是本文要正面回答的问题。结论先给：**作为「逐样本挑数据」的默认方案，它的地位下降了；作为「在有限预算下决定下一步获取什么信息」的方法论，它比以往更重要。** 变化不在于闭环失效，而在于闭环里最贵的那个环节换了位置。

### 四个前提变了

**第一，标注不再是唯一瓶颈。** 大模型可以把标注单价打下来，在多项文本标注任务上，LLM 的表现已经可以超过众包工人[@6]；围绕标注生成、评估与使用的工具链也在快速成熟[@7]。但标注变便宜不等于数据变便宜：验证、抽检、争议处理与评测的成本上升了，瓶颈从「标什么」转向「信什么」。当一条标签的边际成本趋近于零时，按不确定性挑样本省下的钱，可能还不够多跑几轮评估。

**第二，模型不再默认是任务专用的小模型。** 在一个 foundation model 上做 few-shot 或轻量微调时，softmax 概率与 ensemble 分歧的可靠性都在下降：模型可能对自己的错误非常自信，输出还存在语义等价（不同表述、同一含义）的问题。语义熵这类方法通过对多次采样做语义聚类来估计不确定性，比 token 级概率更能预测答案是否正确[@9]，但采样成本高，且仍然只是一个信号，不是价值本身。

**第三，数据目标从「补样本」变成「补能力、补切片、调配比」。** 预训练与后训练的数据规模很大，单条样本的边际价值被稀释；相比逐条挑选，去重、质量过滤、按目标分布做重要性重采样、按能力维度做配比，往往更直接[@15]。在指令微调阶段，按梯度影响，或按复杂度、质量、多样性选择少量数据，已经能在部分任务上接近甚至超过全量训练[@10][@14]。这些方法共享主动学习的内核——用有限预算换更高价值的数据——但操作对象不再是「下一条标什么」。

**第四，三类范式的成本结构也变了。** 生成式查询的边际成本下降最快：候选与预标注都可以由模型生成，但真实性、多样性与合规验证成为新瓶颈；池式仍是最容易组织的形态，只是池子从「未标注的真实样本」变成「真假混合、需要验证的候选」；流式则随着 agent 与在线系统回到前台，因为环境交互和真机时间无法预先收集。

### 仍然成立的部分

**价值是边际量**这一条没有变。无论选的是样本、切片还是任务，价值都取决于当前模型、已有数据、目标分布与获取成本。**批量冗余**没有变：大模型的数据池里重复与近重复往往更多，top-k 的失效模式只会更严重。**分布偏差**没有变：按不确定性选出来的数据，同样会让训练分布偏离真实分布。**成本归一化的评估曲线**也没有变：它仍然是同时比较「更聪明的选择」和「更便宜但更多」的可靠口径。

具体场景上，主动学习在四类问题里仍然划算：

- **冷启动与领域迁移**：新业务、新本体、新传感模态没有现成数据，需要快速定位模型边界；
- **长尾与切片指标**：总体指标已经很高，但稀有类、特定失败模式仍是短板，按切片配额选择比随机采样有效；
- **专家标注昂贵且可验证**：医疗、法律、工业质检、机器人示范，单条成本高，专家能给出可靠标签；
- **测试标签也贵**：主动评测用少量测试标注估计指标，和主动学习共享预算逻辑[@8]。

反过来，当数据已经过剩、标注极其便宜、瓶颈在验证与配比时，逐样本主动学习的收益很容易被淹没。此时更值得做的是**数据选择 + 评测基础设施**，而不是再调一个 acquisition function。

### 形态迁移：从选样本到选切片、选任务、选环境

把经典主动学习与大模型下的对应形态放在一起，可以看到一条清晰的上移路径：

| 经典主动学习 | 大模型下的对应形态 | 选择信号 | 代表工作 |
| --- | --- | --- | --- |
| 池式选样 | 指令微调与后训练数据选择 | 梯度影响、复杂度、质量、多样性 | LESS、DEITA、DSIR[@10][@14][@15] |
| 不确定性采样 | 语义级不确定性与多模型分歧 | 多次采样的语义一致性、评审分歧 | 语义熵[@9] |
| 人工标注 | LLM 预标注 + 人审与抽检 | 一致性、争议率、可验证性 | LLM 标注综述[@7]、LLM 标注者研究[@6] |
| 固定测试集评估 | 主动评测 | 选择最有信息量的测试点并去偏 | active testing[@8] |
| 样本采集 | 任务、环境与评测切片的构造 | 能力缺口、失败模式、覆盖度 | LLM 参与的主动学习综述[@12] |

LLM 在循环中的角色也在变化：它既可以是选择者，也可以是标注者，还可以生成新的候选样本[@12]。当生成与标注都变便宜时，「选择」的对象自然从已有样本扩展到「生成什么、让谁标、在哪里评」。

### 判断表：什么时候还值得做

| 场景 | 建议 | 主要理由 |
| --- | --- | --- |
| 标签极贵且可验证：医疗、法律、工业质检、机器人示范 | 做 | 单条成本高，随机采样浪费预算；专家标签可靠 |
| 长尾与切片指标：稀有类、长尾意图、特定失败模式 | 做，按切片配额 | 平均指标掩盖缺口，按切片选择更直接 |
| 冷启动与领域迁移：新业务、新本体、新模态 | 做 | 没有现成数据，需要快速定位模型边界 |
| 测试标签也贵：上线前的小样本评估 | 做主动评测 | 少量测试标注估计指标，并校正选择偏差[@8] |
| 海量廉价 LLM 标注且可抽检 | 弱化逐样本选择 | 标注不是瓶颈，验证与配比才是 |
| 预训练或大规模后训练数据 | 谨慎 | 单样本边际价值低，去重、过滤与配比更有效[@15] |
| 不确定性不可靠且没有基线 | 先不做 | 偏差与复杂度大于收益[@5] |

### 三个新风险

**标注者偏差会被主动选择放大。** 如果策略专门挑模型不确定的样本，而这些样本恰好也是 LLM 标注最容易出错的样本，错误就会集中进入训练集；模型在下一轮变得更自信，策略更难发现这些错误。缓解方式不是换一个更激进的选择器，而是独立验证：人审抽样、规则校验、交叉模型一致性，或者把「可验证的失败」作为选择信号。

**评测污染与自适应过拟合更隐蔽。** 用同一个测试集反复做选择与评估，测试集事实上参与了训练决策；在大模型时代，benchmark 可能已经出现在预训练数据里，污染不一定表现为分数异常。需要隔离测试集、滚动更新隐藏切片，并记录每一次「因为评测结果而改了什么」。

**优化对象容易错位。** 把 judge 分数当成价值信号，会被 Goodhart：选择器学会迎合评审，而不是解决问题。价值应定义在可验证的下游结果上，例如任务成功率、人工复核通过率、真机执行成功率，而不是评审模型的偏好分数。

## 讨论：场景、范式与工程判断

### 范式选择先于策略排名

三类查询范式的评价口径不同：池式看固定池上的评估曲线，流式看累计遗憾（regret）、延迟反馈与漂移下的表现，生成式看生成分布的覆盖与真实性。公开 benchmark 大多默认池式批量设定，因此论文里的排名不能直接搬到流式或生成式场景。工程上更合理的顺序是：先确定数据怎么来，再决定候选集怎么产生，最后才比较打分器。

### 约束比打分器更早决定结果

项目把实际考虑拆成数据、oracle、规模、工作流、训练成本、指标、可靠性与隐私[@16]。这些约束往往在算法之前就决定了方案形态：池子覆盖不足时换策略没用；标注团队按批次工作就很难做真正的流式；重训成本高时多轮策略的收益会被抵消；测试集不可信时任何选择策略都无法证明自己。

在这些约束下，池式通常是最容易复现的起点；流式只有在样本必须实时处理或分布持续漂移时才有必要；生成式只有在候选无法收集、或需要主动探索未知区域时才值得付出生成与验证成本。

### 尚未解决的问题

- **生成式查询的真实性与多样性如何评估**：生成样本的标签由谁负责，生成分布偏离目标分布时如何发现；
- **流式下的延迟标签与概念漂移**：如何避免策略被短期信号带偏，如何在标签回来之前判断决策质量；
- **LLM 时代的切片级价值**：如何定义「值得补的能力切片」，以及如何避免评测污染与 judge 分数被优化；
- **可验证失败的复用**：如何把 verifier、执行环境或人工复核发现的失败，沉淀成跨轮可复用的选择信号。

这些问题没有统一答案，但都指向同一个判断：主动学习的工程价值，取决于它能否把「下一步获取什么信息」变成一个可验证、可算账的决策。

我对主动学习的看法变过一次。

早期把它当成一组 acquisition function：不确定性、coreset、BADGE，比较谁在 benchmark 上高几个点。后来做数据管道才意识到，这些函数是最容易被替换的部分；真正决定方案能不能落地的是三件事：候选池是否覆盖目标分布、评估是否可信、成本账是否算清。一个平庸的打分器配上干净的测试集和诚实的成本核算，通常比一个精巧的打分器配上泄漏的测试集更有用。

还有一点越来越确定：**范式选择比打分器更早决定结果**。能提前收集就池式，样本按流到达就流式，既没有池子也不能等流就生成式；把三类范式放在同一张 benchmark 上比分数，等于忽略了它们的数据获取成本不同。工程上先问「候选从哪来」，再问「用哪个 scorer」，顺序反了就会做出无法落地的方案。

工程化进展可以分成两层，外加一个共同点：

- **经典监督学习栈**已经相当成熟。[ModAL](https://modal-python.readthedocs.io/) 和 [small-text](https://github.com/webis-de/small-text) 覆盖池式流程、批量选择与文本分类的不确定性估计，[Baal](https://github.com/baal-org/baal) 提供贝叶斯主动学习的实现；标注与复核由 [Label Studio](https://labelstud.io/)、[Argilla](https://argilla.io/) 承担；[FiftyOne](https://voxel51.com/fiftyone)、[Encord Active](https://github.com/encord-team/encord-active) 把数据视图、质量检查与主动选择放进同一个界面。这一层的问题是「都能跑」，难点在接入既有数据管道、权限体系与标注团队的工作流。
- **大模型栈**换了一套组件：数据选择用 LESS、DSIR、DEITA 这类方法，按梯度影响、分布重要性或质量与多样性打分；不确定性从 softmax 概率换成多次采样的语义一致性（semantic entropy）或评审分歧；标注从纯人工换成 LLM 预标注加人审；评估从固定测试集换成主动评测与小样本估计。
- **共同点**是没有哪一个库同时解决「选、标、训、评」。实际落地都是拼装，而拼装的接口是数据版本与评测口径，不是算法 API。这也是我认为工程化真正沉淀下来的部分：不是某个 scorer，而是一条能复现「这批数据为什么进来、花了多少、换来了什么」的管道。

基于这些，我有几个判断：

1. **范式选择是场景问题，不是算法排名。** 先看候选能不能提前收集、样本是否按流到达、能否自己生成；这三件事决定了池式、流式还是生成式，也决定了评估口径。
2. **acquisition function 不是护城河，闭环才是。** 能把「这批为什么被选、花了多少钱、换来了多少指标」讲清楚的团队，已经赢过大多数只比较 scorer 的工作。
3. **今天最值得投入的是 evaluation infrastructure。** 固定测试集、分片指标、成本账本、选择日志，这四样同时服务主动学习、数据选择和模型发布；没有它们，主动学习的收益无法与它自己引入的偏差区分开。
4. **大模型让「不确定性」更不可靠，反而让「可验证的失败」更值钱。** 与其问模型哪里不确定，不如问哪里能被 verifier、执行环境或人工复核判定为错；后者是可积累的信号，前者只是一次前向传播的副产品。
5. **「主动」的对象正在上移。** 从选样本，到选切片、选任务、选环境、选评测点。Agent 与强化学习场景是这套思想最自然的回归，因为环境步数和真机时间才是真正贵的资源。
6. **判断标准没有变。** 相对哪个基线、在哪个指标上、每单位成本改善多少。先证明随机采样不够用，再谈策略。
:::
