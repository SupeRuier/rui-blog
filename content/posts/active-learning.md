::: tldr
主动学习要回答的问题很朴素：**标注贵、预算有限，而未标注样本对目标任务的贡献并不相同**，能否让模型主动决定下一批请专家标什么？

本文的出发点是：**样本的「价值」不是一个固有属性，而是一个边际量**。它取决于当前模型、已有的已标注集合、目标任务分布，以及标注成本。同一个样本在训练早期和后期、在已有集合不同时，价值可以完全不同。这一点决定了后面所有工程决策：

- 批量选择要显式处理**冗余**，否则 top-k 会选出一批高度相似的样本；
- 选择过程本身会引入**分布偏差**，被选中的集合不再代表真实分布；
- 验证只能靠**学习曲线与成本归一化**，报告「达到某指标需要多少标注」，而不是只报最终值。

最后一节列出**策略失效的六种情形**——其中最常见的一种是：随机采样其实已经够用，策略带来的收益小于它引入的偏差与复杂度。
:::

::: question
在标注成本与训练成本约束下，如何定义「值得标注」的样本，并检验新增数据的边际收益？
:::

我在 GitHub 整理的 [awesome-active-learning](https://github.com/SupeRuier/awesome-active-learning) 不只是论文清单，还按问题场景、选样策略、理论、实践和应用组织资料[@1]。它引出的基本问题很朴素：标注贵、预算有限，而未标注样本对目标任务的贡献并不相同，能否让模型主动决定下一批请专家标什么？

## 经典问题设定

给定少量已标注集合、一个较大的未标注数据池和有限的查询预算，训练一个初始模型，按策略选择一批候选交给人工 / 领域专家（oracle）标注，更新模型后继续下一轮。最终目标是用更少标注达到相近或更好的泛化表现[@3]。这是**模型—选样—专家—再训练**的迭代式机器学习架构，不是简单按难度排序的一次性数据清洗。

## 选样策略：先看四类问题

[项目的池式分类框架](https://github.com/SupeRuier/awesome-active-learning/blob/master/contents/pb_classification.md)可粗分为：**信息量**（不确定性、模型间分歧、模型变化）；**代表性**（分布覆盖、聚类和密度）；**预期改进**（选择可能真正降低误差的样本）；**学习评分**（直接学习样本价值）[@2]。批量选择还应处理样本间冗余，目标和标注成本不同也会改变策略选择。

## 怎样验证它有用

固定测试集与标注预算，画出模型表现随累计标注量变化的学习曲线，与随机采样和简单基线比较；同时报告查询耗时、标注成本、选择偏差及不同数据分布上的效果。后续再讨论如何把这套经典闭环迁移到视觉长尾挖掘和更大规模的数据价值评估；博士阶段的具体研究成果需要逐篇核对，不在这份初步框架中预设结论。

## 样本价值是边际量，不是固有属性

一个样本「值不值得标」，取决于四件事：**当前模型**、**已有的已标注集合**、**目标任务分布**、以及**标注成本**。因此它是边际量——在已有集合之上再加入样本 $x$ 所带来的期望收益，而不是 $x$ 自身携带的某种分数。

最常见的混淆是把**不确定性等同于价值**。高不确定性至少有两种与目标无关的来源：

- **标注噪声或本身有歧义的样本**：标了也只是把一个模糊标签固化下来；
- **分布外样本**：模型不确定是因为「没见过这种输入」，而不是「这类输入在目标分布上重要」。

两种情况都会让基于不确定性的排序退化。更可操作的写法是把价值写成比值——**预期误差降低 / 标注成本**——并且**在批次层面估计**而不是逐样本估计，因为样本之间存在冗余：两个高度相似的样本各自分数都不错，但只值得标其中一个。

## 批量选择：从单点排序到组合覆盖

按单样本分数取 top-k 是最省事的做法，也是最容易失效的做法：如果池子里存在大量近乎重复的样本，top-k 会几乎全部落在同一个簇里。批量选择因此要额外处理三件事：

1. **冗余惩罚**：在批次内显式减去样本间相似度，或按簇分配配额；
2. **覆盖约束**：把选择看成在特征空间里的覆盖问题，而不是排序问题；
3. **异质成本**：不同样本的标注成本并不相等（需要重新采集、需要专家判断、需要多标注者交叉验证），「每个样本一票」的预算模型过于简化。

还有一个容易被忽略的口径问题：**评价指标会改变策略的评价结果**。当类别高度不平衡时，一个合理的选择策略会把预算集中到稀有类，这在「总体平均准确率」上甚至可能不如随机采样，而在「稀有类召回」上明显更好。因此策略对比必须绑定明确指标，否则结论会随指标翻转。

## 分布偏差与选择偏差

主动学习与普通训练有一个根本差别：**训练数据的分布是被策略选出来的**。由此带来三类偏差，都需要显式报告：

- **先验偏移**：稀有类被过度采样，训练集类别先验不再等于真实先验；
- **选择偏差**：被选中的样本集中在「模型当前不确定」的区域，而模型未覆盖的区域被持续忽略；
- **学习曲线本身的偏差**：在同一个测试集上反复评估并据此做决策时，测试集事实上参与了选择过程。

前两类可以用「选中集合与候选池的分布距离」「类别先验变化」来监控。第三类只能靠制度性约束解决：**测试集必须与选择过程隔离**，既不参与打分，也不参与决定下一轮选什么。这与数据体系那篇里按来源分层记录数据配方的要求是同一条纪律[@4]。

## 训练与再评估：边际收益怎么测

验证一套主动学习方案，核心是**学习曲线**：横轴是累计标注量（成本异质时应改为累计标注成本），纵轴是目标任务指标，同时画出随机采样与「按简单启发式排序」两条基线。要把结论说清楚，还需要补四件事：

- **边际收益递减**：曲线通常前段陡、后段平。因此更有信息量的报法是「达到指标 X 需要多少标注」，而不是预算用尽时的最终值；
- **成本归一化**：报告「每单位标注成本带来的提升」，否则容易被更便宜但更大量的标注掩盖；
- **多轮 vs 一轮**：一次性选一大批，与分多轮、每轮重训后再选，效果通常差别很大。多轮更好，但重训开销必须计入成本；
- **重复实验与方差**：学习曲线的方差来自初始化、选样随机性与池子划分。单次实验里两条线交叉，往往不构成有效差异。

## 什么时候主动学习不划算

选择策略不是默认更优的。以下六种情形里，它可能不产生收益，甚至更差：

1. **模型不确定性不可靠**——模型校准很差，对自己的错误很自信，基于不确定性的排序退化为随机；
2. **候选池本身不覆盖目标分布**——选得再好也补不上缺失的区域，问题出在数据来源而不是选择；
3. **标注噪声主导**——策略优先选中的是有歧义的样本，提升的其实是拟合噪声的能力；
4. **分布外样本被优先选中**——高不确定性来自「与训练分布不同」，而非「难但相关」；
5. **预算内目标已饱和**——简单场景下随机采样已接近最优，策略收益小于它引入的偏差与工程复杂度；
6. **代价不对称**——策略的推理、重训与维护开销超过了省下的标注成本。

由此得到一条实践顺序：**先证明随机采样不够用，再引入选择策略**。反过来做，等于在还没有建立基线之前就先接受了偏差。

## 本文范围

本文只讨论**数据价值与样本选择**这个问题本身。视觉长尾与多模态检索那一类主题——大规模检索、长尾分布下的表征学习——已不在本站范围内，本文也不接手；上一节提到「迁移到视觉长尾挖掘」只是记录当时的思路走向，不是本文的写作计划。涉及真实世界与具身场景的数据来源分层、质量与成本权衡，见数据体系与可控数据生成两篇[@4]。

::: my-take
我认为「样本价值」最容易被误当成一个静态属性，而它其实是**边际量**：同一个样本的价值随当前模型、已有标注集合和标注成本而变。承认这一点之后，判断一套主动学习方案是否成立就有了一个很硬的标准——它必须能说出「相对于哪个基线、在哪个指标上、每单位标注成本改善了多少」。

三项缺任何一项，「为什么值得标这一批」就还没有被回答。这也是我把「先证明随机采样不够用」放在引入策略之前的原因：没有基线的选择策略，无法与它自己引入的偏差区分开。
:::
