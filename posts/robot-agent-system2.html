ROBOT AGENT · FRAMEWORK

Robot Agent System 2：规划、执行与系统闭环

框架草稿：用于整理 Robot Agent Runtime 的核心模块与工程边界。

Robot Agent 的关键不只是生成一个计划，而是让长期任务在物理环境中持续运行。上层 Planner、底层 Policy、环境观测和执行反馈需要由一个长期存在的 Runtime 组织起来。

系统主链路

总体任务首先被解释为可执行的阶段或子任务，Policy 根据当前指令和观测产生动作，Harness 持续维护任务状态，并在完成、失败或环境变化时决定继续、重试或重新规划。

核心模块

  • Task 与 Goal 状态管理
  • Planner–Policy 调度
  • Context 与 Memory
  • 执行监控、完成判定和失败恢复
  • 仿真评测、Trace 与 Replay
  • ROS 集成、模型服务和端云通信

后续将重点整理不同系统在规划粒度、调度频率、上下文生命周期和闭环恢复方式上的差异。
